# Character Creator

## Objective

Create a character creation function that validates the character's name and attributes, then generates a status display based on the character's strength, intelligence, and charisma points.

The goal of this exercise is to practice input validation, conditional logic, string manipulation, and formatting output.

## Concepts Practiced

- Functions
- Parameters and return values
- Input validation
- Conditional statements (`if`, `elif`, `else`)
- Data type checking (`isinstance`)
- String manipulation
- String slicing
- Formatted strings (f-strings)
- Nested functions
