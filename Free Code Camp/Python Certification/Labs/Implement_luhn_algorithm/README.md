# Implement the Luhn Algorithm

## Objective

Create a program that validates identification numbers, such as credit card numbers, using the Luhn algorithm.

The program should process the digits of the number, apply the Luhn checksum rules, and return `"VALID!"` when the number passes the validation or `"INVALID!"` when it does not.
