# Player Movement System

## Objective

Create an abstract player system where different types of players can have their own movement rules.

The goal of this exercise is to practice object-oriented programming by creating an abstract base class, implementing inheritance, and defining specific behaviors in child classes.

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Abstract classes (`ABC`)
- Abstract methods (`@abstractmethod`)
- Inheritance
- Method overriding
- The `super()` function
- Lists and tuples
- Random selection (`random.choice`)
- State management
