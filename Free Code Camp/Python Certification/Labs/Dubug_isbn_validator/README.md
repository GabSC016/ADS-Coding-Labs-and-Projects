# ISBN Validator

## Objective

Create a program that validates ISBN-10 and ISBN-13 codes by checking the calculated check digit against the provided ISBN code.

The goal of this exercise is to practice error handling, input validation, functions, and implementing validation algorithms.

## Concepts Practiced

- Functions
- Parameters and return values
- Input validation
- Exception handling (`try`, `except`)
- Handling errors (`TypeError`, `ValueError`, `IndexError`)
- String manipulation
- Lists and loops
- Conditional statements
- Algorithms and calculations
