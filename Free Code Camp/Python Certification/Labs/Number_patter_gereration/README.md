# Number Pattern Generator

## Objective

Create a function that generates a sequence of numbers from 1 up to a given integer value.

The function must validate the input argument and return appropriate messages when invalid values are provided.

## Concepts Practiced

- Functions
- Parameters and return values
- Type checking (`isinstance`)
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`)
- Lists
- String conversion
- String formatting and joining (`join`)
