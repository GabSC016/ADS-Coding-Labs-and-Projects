# Planet Class

## Objective

Create a `Planet` class that represents a planet with information such as name, type, and the star it orbits.

The goal of this exercise is to practice object-oriented programming by creating classes, validating input data, defining methods, and customizing object string representation.

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and objects
- Constructor method (`__init__`)
- Attribute validation
- Exception handling (`TypeError`, `ValueError`)
- Methods
- String representation (`__str__`)
- Formatted strings (f-strings)
