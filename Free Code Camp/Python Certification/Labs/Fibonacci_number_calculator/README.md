# Build an Nth Fibonacci Number Calculator

## Objective

Create a program that calculates the **Nth number in the Fibonacci sequence** using an iterative dynamic programming approach.

The program starts with the base values `0` and `1`, then calculates each subsequent number by adding the two previous numbers.

For example, `fibonacci(15)` returns `610`.
