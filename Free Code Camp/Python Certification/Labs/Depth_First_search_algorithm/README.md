# Build a Depth-First Search Algorithm

## Objective

Create a program that performs a Depth-First Search (DFS) on a graph represented by an adjacency matrix.

The program starts from a given node and recursively explores connected nodes, keeping track of visited nodes and returning a list of all reachable nodes.

The goal is to practice graph traversal, recursion, and tracking visited nodes to avoid exploring the same node multiple times.

## Concepts Practiced

* Functions
* Recursion
* Lists
* Matrices
* Boolean values
* `for` loops
* `enumerate()`
* Conditional statements (`if`, `else`)
* Logical operators (`and`, `not`)
* Graph traversal
* Adjacency matrices
* Depth-First Search (DFS)
* Tracking visited nodes
