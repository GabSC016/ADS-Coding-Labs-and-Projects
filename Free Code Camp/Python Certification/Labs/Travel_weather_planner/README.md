# Build a Travel Weather Planner

## Objective

Create a program that determines if transportation is available based on the distance, weather conditions, and available transportation options.

The goal is to practice decision-making logic by evaluating different conditions and returning a boolean result (`True` or `False`).

## Concepts Practiced

- Conditional statements (`if`, `elif`, `else`)
- Boolean values
- Logical operators (`and`, `or`, `not`)
- Comparison operators
- Control flow
