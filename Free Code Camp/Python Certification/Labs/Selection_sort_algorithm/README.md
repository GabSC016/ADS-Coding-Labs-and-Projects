# Build a Selection Sort Algorithm

## Objective

Create a program that sorts a list of numbers in ascending order using the Selection Sort algorithm.

The goal is to practice algorithmic thinking by repeatedly finding the smallest element in the unsorted portion of the list and moving it to its correct position.

## Concepts Practiced

* Selection Sort algorithm
* Lists and list manipulation
* `while` loops
* `for` loops
* `range()`
* Indexes and positions
* Variables and reassignment
* Comparison operators (`>`)
* Swapping values
* Control flow
* Algorithmic logic
