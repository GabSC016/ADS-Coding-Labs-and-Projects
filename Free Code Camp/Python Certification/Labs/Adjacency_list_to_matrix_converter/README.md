# Build an Adjacency Matrix Converter

## Objective

Create a program that converts a graph represented as an adjacency list into an adjacency matrix.

The program should create a square matrix where each row and column represents a node. If a connection exists between two nodes, the corresponding position in the matrix should contain `1`. Otherwise, it should contain `0`.

## Concepts Practiced

* Dictionaries
* Lists
* Nested lists
* `for` loops
* List indexing
* Matrix representation
* Graphs
* Adjacency lists
* Adjacency matrices
* Data structure conversion
