# Game Character Class

## Objective

Create a `GameCharacter` class that represents a game character with attributes such as name, health, mana, and level.

The goal is to practice object-oriented programming by creating properties, controlling attribute updates, and implementing methods that modify the character's state.

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and objects
- Constructor method (`__init__`)
- Private attributes
- Properties (`@property`)
- Setters
- Data validation
- Methods
- String representation (`__str__`)
- State management
