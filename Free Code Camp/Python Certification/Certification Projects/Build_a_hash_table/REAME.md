# Build a Hash Table

## Objective

Create a `HashTable` class that stores and manages key-value pairs using a custom hash function.

The goal is to practice implementing a basic hash table from scratch, including adding, removing, and looking up values while handling hash collisions.

## Concepts Practiced

* Classes and objects
* Dictionaries
* Methods
* Hash functions
* Key-value pairs
* Dictionary manipulation
* Conditional statements (`if`, `else`)
* Logical operators (`and`)
* `ord()` function
* Collision handling
* `pop()` method
* Dictionary merging
* Searching and retrieving values
