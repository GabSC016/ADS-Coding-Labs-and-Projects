# Rectangle and Square Classes

## Objective

Create a program that models rectangles and squares using object-oriented programming.

The goal of this project is to practice inheritance by creating a `Square` class that extends the `Rectangle` class, while maintaining specific behaviors and properties.

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance
- Parent and child classes
- The `super()` function
- Method overriding
- Instance attributes
- Encapsulation of object state
- Mathematical calculations
- String representation (`__str__`)
