Implement the Tower of Hanoi Algorithm
Objective

Create a program that solves the Tower of Hanoi puzzle using recursion.

The goal is to move all disks from the first rod to the last rod while following the puzzle rules and recording every move.

Concepts Practiced
Recursion
Base and recursive cases
Lists
pop() and append()
Function parameters
String formatting
join()
Breaking problems into smaller subproblems
Key Learning

The main challenge of this project was understanding recursion. The solution uses a base case for one disk and a recursive case that reduces the problem until reaching that base case.

The project reinforced the importance of understanding the problem and structuring the logic before writing the code.
