# User Settings Manager

## Objective

Create a program that manages user settings using a dictionary.

The goal of this exercise is to practice creating functions that can add, update, delete, and display settings while handling existing and non-existing values.

## Concepts Practiced

- Functions
- Dictionaries
- Dictionary methods (`update`, `pop`, `items`)
- Key and value manipulation
- Conditional statements (`if`, `elif`, `else`)
- String formatting (f-strings)
- Input normalization with `.lower()`
- Data management
